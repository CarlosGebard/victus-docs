# Victus Architecture Decision Records

Architecture Decision Records define decisions that affect system boundaries, contracts, operations, or long-term architecture.

## Records

| ADR | Status | Title |

## Rules

- Use ADRs for architecture, infrastructure, contract, or operational decisions.
- Keep ADRs short and explicit.
- Link ADRs from affected architecture and contract documents.
- Do not use ADRs for implementation notes that belong in an owning repository.
